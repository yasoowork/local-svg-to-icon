# Local SVG to Icon

軽量な SVG アイコン変換ツール。

SVG コードから：

- favicon.ico
- PNG
- App Icon

などを生成できる。

すべての処理はブラウザ内で完結し、
SVG や画像データをサーバーへアップロードしない。

---

# ■ Background

既存の SVG / favicon 変換サイトには：

- 広告が多い
- 動作が重い
- UI が複雑
- 英語のみ
- アップロード必須
- プライバシー面が不透明

などの課題がある。

また、
favicon や app icon の作成では：

- 小サイズで潰れていないか
- ダークモードで視認できるか
- padding が適切か

など、
変換だけでなく「確認」が重要になる。

---

# ■ Goal

Local SVG to Icon は：

- 軽量
- シンプル
- ブラウザ完結
- 日本語対応
- 開発者向け実用性重視

を重視した、
SVG アイコン生成ツールを目指す。

---

# ■ Core Features

- SVG コード入力
- SVG ファイル Drag & Drop
- リアルタイムプレビュー
- PNG 出力
- favicon.ico 出力
- App Icon 出力
- favicon サイズプレビュー
- ダーク / ライト背景確認
- browser tab プレビュー
- padding 調整

---

# ■ Non Goals

以下は現時点では対象外：

- 高度な画像編集
- SVG 描画エディタ
- AI 画像生成
- PNG / ICO → SVG 高精度変換
- クラウド保存
- アカウント機能

---

# ■ Philosophy

最短で：

入力
→ 確認
→ ダウンロード

できる UX を重視する。

高度な設定は必要時のみ表示し、
基本操作を邪魔しない。
